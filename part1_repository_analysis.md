## Why I Selected MetaGPT

I chose MetaGPT because it is mainly built using Python and the overall project structure was easier for me to understand compared to the other repositories. Since the project is related to AI agents and workflow automation, it also matched my background in AI and software development. The repository has clear documentation, modular code organization, and understandable PRs, which made the analysis process simpler.

The project is designed to simulate a software company using multiple AI agents. Different agents perform tasks such as planning, coding, reviewing, and managing workflows. This makes the repository interesting and practical for understanding modern AI-based software systems.
